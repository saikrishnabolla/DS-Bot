# 发版前真机检查

CI 不能验证安装、系统窗口、输入法、高 DPI 和自动更新。每次发版前在 Windows 上做一遍；改动涉及 macOS 时，在 macOS 上也做一遍。

每项记「通过 / 不通过 / 备注」。不通过时保留截图和错误原文，结果贴在 Release PR 里。

## 准备

- 确认 `app/package.json` 和 `ds-bot/package.json` 版本相同。
- 在 `ds-bot/` 运行 `npm ci && npm test && npm run build && npm run lint`。
- 在 `app/` 运行 `npm ci && npm test && npm run build && npm run check-packed && npm run check-lifecycle`。
- 用 Release 工作流的 dry run 生成 Windows 安装包和 macOS zip。
- 准备一个可用的模型 API key。其他密钥测试只用假值。
- 测试升级前备份 Cue 数据目录。
